Clan Palette Studio

Recolour eyes, coats, patterns and markings using the game's real colour slots. The cat updates as you go. When it looks right, copy the palette into a mod and install it.

Appearance only: a palette redraws a slot in a new colour, but your cat keeps the same slot, so traits and stats don't change. Suggested names stay with the slot too, so a recoloured "Ember" orange still suggests fiery names.
