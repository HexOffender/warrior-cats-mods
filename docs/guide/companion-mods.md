# Mods that go with Clan Mod Studio

## What it changes in the game

Four mods come with Clan Mod Studio. Each is a mod of its own, made by the studio's makers, and each brings
something into the game that the studio's pages make or need:

- **Menu pages**: your cat, the world, quests, fights and cheats in the in-game mod menu (Insert).
- **Sandbox mode**: a Sandbox Mode on the game's main menu, where the cats and questlines you make on the
  Characters and Questlines pages turn up.
- **Creator palettes**: your new colours and coat presets as choices in the cat maker's colour pickers.
  It comes with ten themed palettes, which go in switched off, and Coat presets, which goes in on.
- **Emote wheel**: hold a key for a wheel of your emotes and the game's own poses (its description on the
  Mods page says which key).

How they get there: each is a small program that runs inside the game, through the script loader. So each
needs the script loader, and mods that run code allowed (Get set up asks once). Clan Mod Studio fetches
them from their pages on GitHub.

## A five-minute first try

1. On the Mods page, find the card **Mods that go with Clan Mod Studio**.
2. Press **Add** on Sandbox mode.
3. If its chip says **Needs scripts allowed**, press **Allow** on **Let mods run their own scripts** in Get
   set up (or tick **Allow mods that run code** under Options, on the Settings and repair page).
4. Press **Play**.
5. On the game's main menu, there's Sandbox Mode.

## What you can and can't do

You can:

- Add all four at once with **Add all four** in Get set up, or one at a time with **Add** on its row.
- See where each one stands from its chip: **Not added**, **In, 0.4**, **Off**, **Needs scripts
  allowed**, **Newer one out: 0.5**, **Needs a newer Clan Mod Studio** or **No release yet**.
- Press **Check for newer versions** to ask GitHub, and **Get the latest** to update one. An update keeps
  whether it's on and your own settings (the Emote wheel's key, Menu pages' cheats). The older copy is kept
  with your removed mods.
- Add one from a .zip you downloaded yourself: drop it on **Add a mod**, as any mod.
- Switch any of them off on its card under Your mods, like any mod.

You can't:

- Add one that has no release yet. Its row says **No release yet**: the owner of that mod has to publish
  one on GitHub first. Until then, nothing is wrong on your side.
- Use one that needs a newer Clan Mod Studio than yours: get the newer Clan Mod Studio first.
- Have them in the game with mods that run code off: they're all programs that run in the game.

## Did it reach the game?

- On the card, the chip says **In** with its version, in green.
- Under Get set up, "Not in the game yet" lists it until you press **Play** or **Apply to game**.
- In the game: Insert opens the mod menu with its pages (Menu pages); Sandbox Mode is on the main menu
  (Sandbox mode); the cat maker's colour pickers have a row of your colours (Creator palettes); holding the
  Emote wheel's key shows the wheel.

## Common mistakes

- **The chip says Needs scripts allowed.** Allow mods that run code (Get set up, or Options on the Settings
  and repair page), then **Play**.
- **The chip says Off.** Press **Switch on**.
- **"GitHub is turning requests away for now."** GitHub answers only so many questions an hour. Wait an
  hour, or download the .zip from its page and drop it on **Add a mod**.
- **"No release yet."** Nothing to fix here: that mod's owner hasn't published it yet. Its row has a link
  to its releases.

## Undo

- Before Play: switch it off on its card, or **Remove** it (under its **More**).
- After Play: switch it off and press **Play** again; it comes out of the game.
- After **Get the latest**: the older copy is kept; remove the new one, then **Put it back** on the
  Settings and repair page.
- What one of them wrote into your save (a sandbox cat's progress, say) stays in your save: put back a save
  backup to undo that ([Settings and repair](settings.md)).
