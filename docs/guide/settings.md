# Settings and repair

## What it changes in the game

- **Options**: the game's console, whether mods may run code, and the mod menu's key, controller button
  and size. They reach the game the next time you press **Play** or **Apply to game**; the console from the
  next time the game starts.
- **Backups and repair**: copies of your save, put back when you need them; mods you removed, put back; a
  check of your mods; and taking every mod out of the game.
- **Make your own mod**: an empty mod to start from.

How it gets there: the options are kept in your settings file and written into the mod menu and the script
loader when you apply. A backup is a copy of the game's save folder, kept in your files' folder.

## A five-minute first try

1. Open **Settings and repair**.
2. Under **Options**, choose a key in **Opens with** for the mod menu.
3. Press **Back up now** under **Save backups**: a copy of your save appears in the list.
4. Press **Play**. In the forest, the key you chose opens the mod menu.

## What you can and can't do

You can:

- Allow mods that run code (**Allow mods that run code**), after a warning that names your mods that do.
  Get set up asks the same thing once, on the Mods page.
- Choose the mod menu's key, the controller button that opens it too, and its size.
- Switch the game's console on, and say whether Menu pages starts with cheats on.
- Back up your save at any time, and put any backup back (**Restore**). Restoring makes a copy of the save
  you have first.
- Bring back a mod you removed, or the older copy of one you replaced (**Put it back**).
- Check every mod without putting anything in the game (**Check my mods**).
- Take every mod out of the game (**Take all mods out of the game**). Your mods stay in your mods folder.

You can't:

- Restore a save while the game is running: close it first.
- Back up a save that isn't there yet: start the game once and get into the forest.
- Use the game's console without the script loader and its console mod.

## Did it reach the game?

- After changing the mod menu's key, button or size, the chip at the top asks for an Apply; **Play** puts it
  in. The console and cheats change from the next time the game starts.
- After allowing mods that run code, the Mods page's cards stop saying "Runs code, so the game won't get it
  until you allow mods that run code".
- After **Restore**, the toast names the files put back.
- After **Take all mods out of the game**, the log at the bottom right says what came out.

## Common mistakes

- **"I allowed mods that run code but nothing changed."** Press **Apply to game** (top right) or **Play**:
  allowing doesn't put anything in by itself.
- **"Take all mods out of the game, and Play put them back."** Play puts your mods in. To play without
  them, switch them off on the Mods page first, or start the game from Steam.
- **"My save edits came back after restoring."** The next Apply writes your mods' save changes again; switch
  those mods off first to keep them out.

## Undo

- An option: change it back, then **Play**.
- Allowing mods that run code: untick **Allow mods that run code**, then **Apply to game**: they come out.
- A restore: the save you had is in the list too (its name ends in before-restore); **Restore** it.
- **Take all mods out of the game**: **Play** or **Apply to game** puts your mods back in.
